# Lean materials (separate effort)

These files are a local copy of a Lean formalization effort. They are not part of the Python package `counting_sat_algebra`. This repository does not build them, import them, or check them with Lean.

- [`378.md`](378.md) — scope note from `openai/math`, `lean/docs/378.md`. It states the aim of that formalization: for fixed \(k \ge 2\), a deterministic machine that exactly counts satisfying assignments of a canonically encoded \(k\)-CNF, within the time and visited-tape bounds written in the note. The October 25 manuscript’s sharper counting bound is quoted there as scope for that effort.
- [`SubexponentialSAT.lean`](SubexponentialSAT.lean) — scaffold linked from that note as `ComparatorChallenges/SubexponentialSAT.lean` (namespace `OAI.Algorithms.SubexponentialSAT`). It defines CNF evaluation, a canonical encoding, a primitive-machine trace, and visited tape cells. The main statement, `exact_count_and_sat`, ends in `sorry`.

In Lean, `sorry` is a placeholder for an unfinished proof. The declaration can be type-checked while the proof is absent. This file does not prove `exact_count_and_sat`, and it does not prove Theorem 1.1 of the preprint.

The Python package version 0.16.0 checks finite instances of interpolation, a blocked sum, a matrix slice of side length at most 256, Hermite recovery of \(H(0)\), occurrence copying, a parameter scan, exact reference conditional-expectation schedules, rational design checks, streamed shared-measurement Taylor recovery, and structured full-parameter coordinate queries. It also constructs a sparse admitted placement at n=16384, Q=3, R=2, and counts supplied DIMACS CNFs through independently placed components. A disconnected 32769-variable instance has exact count 7^10923. The shared-measurement sum on the 16384-variable placement is refused before enumeration; Step 14 recovers its exact count 1 from the same replacement polynomials through disjoint supports, scanning 96 local Boolean vectors with memoization and 49152 without it. Step 15 counts some connected supports by finite Taylor tensor elimination when intermediate tables fit explicit budgets: the 13-variable path counts as 610, and a 1024-variable path plus two free bits counts as 4·Fibonacci(1026). A width-13 factor is refused before any numerical table is built. Step 15 is not Appendix D's general modular contraction or its asymptotic bound, and these finite results do not prove this Lean statement. The complete general-input and asymptotic pipeline remains open. `theorem_1_1_complete` and `lean_proof_complete` stay false.
